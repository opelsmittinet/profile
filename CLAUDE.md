# Portfolio 2026 - Patcharida Smittinet

A premium, responsive personal portfolio website built with HTML, Vanilla CSS, and JavaScript.

## Design Guidelines
* **Color Palette (Executive Trust)**:
  * Primary: Midnight Navy (`#0b132b` / `#0f172a`)
  * Accent: Matte Champagne/Gold (`#b8956c`)
  * Backgrounds: Pearl Grey/Slate (`#f8fafc`) and Warm Cream (`#fdfaf6`)
* **Header**: Fixed glassmorphic navbar (`backdrop-filter: blur(12px)`).
* **Mobile Menu**: Interactive hamburger button (`#hamburger-btn`) toggling an active sliding right side-drawer (`#nav-links`).
* **Interactions**: Subtle zoom transitions on cards, custom hover states, and testimonial carousel with manual interaction resets.

## Project Structure
* `index.html` - Homepage (Hero, About, Expertise, Case Study, Testimonials, Contact)
* `experience.html` - Career journey list & timeline
* `style.css` - Theme styles, layout grids, components, and media queries
* `script.js` - Scroll reveals, navigation drawer, and testimonial slider
